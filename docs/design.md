# 분산일 대시보드 설계

## 목적

KOSPI, KOSDAQ, NASDAQ Composite, S&P 500, Dow Jones Industrial Average의 최근 1년 일봉 데이터를 가져와 지수 변화, 거래량 변화, 분산일 여부를 한 화면에서 확인한다.

## 분산일 정의

사용자 정의를 그대로 적용한다.

- 당일 종가가 전 거래일 종가보다 0.2% 이상 하락한다.
- 당일 거래량이 전 거래일 거래량보다 많다.
- 두 조건을 모두 만족하면 분산일로 표시한다.

## 데이터

- 기본 데이터 소스: Yahoo Finance chart API
- 티커
  - KOSPI: `^KS11`
  - KOSDAQ: `^KQ11`
  - NASDAQ Composite: `^IXIC`
  - S&P 500: `^GSPC`
  - Dow Jones Industrial Average: `^DJI`
- 조회 범위는 13개월로 가져온 뒤 마지막 데이터 일자 기준 최근 1년만 표시한다.
- 13개월을 가져오는 이유는 최근 1년 첫 거래일의 전일 대비 여부를 계산하려면 직전 거래일 데이터가 필요하기 때문이다.

## 화면 구성

- 지수 선택 버튼
- 최근 25거래일 분산일 수
- 최근 1년 분산일 수
- 최신 종가와 거래량
- 최근 1년 차트
  - 종가: 선 그래프
  - 거래량: 막대 그래프
  - 분산일: 종가 위치의 빨간 점
- 최근 25거래일 내 분산일 표
- 최근 1년 분산일 표

## 실행 방식

의존성 설치 없이 Python 표준 라이브러리만 사용한다.

- `python3 app.py`
- 브라우저에서 `http://127.0.0.1:8000`
