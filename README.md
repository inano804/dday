# 분산일 대시보드

KOSPI, KOSDAQ, NASDAQ, S&P 500, Dow Jones의 최근 1년 일봉을 조회해 분산일을 표시하는 로컬 웹 프로그램입니다.

분산일 기준은 "전 거래일 대비 종가 0.2% 이상 하락 + 거래량 증가"입니다.

## 실행

```bash
python3 app.py
```

브라우저에서 아래 주소를 엽니다.

```text
http://127.0.0.1:8000
```

## 구성

- `docs/design.md`: 계산 기준과 화면 구성
- `app.py`: 로컬 서버
- `api/_market.py`: 로컬/Vercel 공용 데이터 조회와 계산
- `public/index.html`: 웹 대시보드
- `public/dashboard.js`, `public/dashboard.css`: 화면 동작과 스타일
- `docs/security-performance-review.md`: 보안 및 성능 점검 결과와 한계
- `scripts/refresh_krx.py`: 배포용 KRX 저장본 갱신

## 데이터 출처

최신 KRX 저장본이 있으면 사용하고, 오래되었거나 새로고침한 경우 Yahoo Finance에서 13개월 일봉을 한 번에 조회합니다. Yahoo의 두 서버를 각각 최대 4초씩 조회하며, 실패하면 저장된 데이터와 기준일 경고를 표시합니다. 저장본도 없으면 오류를 반환합니다.

화면 요청에서는 KRX 과거 일봉 및 시장 폭을 수집하지 않습니다. 시장 폭은 저장된 날짜만 표시하므로 갱신하지 않은 날짜는 `-`로 표시됩니다. KRX 공식 저장본은 `.env`의 `KRX_AUTH_KEY`를 설정한 뒤 별도 작업으로 갱신하고 재배포합니다.

```bash
python3 scripts/refresh_krx.py
```

위 작업은 KRX 호출 간격과 재시도 때문에 수 분 걸릴 수 있습니다. 자동 실행 일정은 등록되어 있지 않습니다.

일반 응답은 서버에서 10분, Vercel CDN에서 5분(추가 10분 동안 갱신 전 응답 허용) 재사용합니다. 브라우저 탭도 생성 시각 기준 10분 이내 데이터를 재사용하며, 오래된 저장본은 먼저 표시한 뒤 다시 조회합니다. 새로고침은 모든 캐시를 우회해 원본을 재조회합니다. 실패 응답과 오래된 저장본 대체 응답은 CDN에 저장하지 않습니다.

동일 서버 프로세스에서 같은 지수의 조회가 겹치면 성공한 원본 조회 결과를 공유합니다. 개별 새로고침은 기존 캐시를 재사용하지 않으며, 요청 중 완료된 원본 조회만 공유합니다. 여러 서버 인스턴스에 걸친 전역 요청 제한은 아닙니다.

## 보안

화면의 동적 문자열은 HTML로 해석하지 않고 텍스트로 표시합니다. CSP는 같은 출처의 스크립트와 스타일만 허용하며, 인라인 스크립트와 다른 사이트의 프레임 삽입을 차단합니다. API는 쿼리 길이, 항목 수, 허용 값과 중복 항목을 검사하고, 조회 오류의 내부 세부 내용은 사용자에게 보내지 않습니다.

손상된 브라우저 저장 데이터는 폐기하고 다시 조회합니다. 버전이 명시된 차트 라이브러리 파일에만 장기 캐시를 적용하며, 앱 파일은 배포 시 재검증됩니다.

## 검증

```bash
python3 -m unittest discover -s tests -v
node --test tests/loading.test.cjs
```

실제 Chromium 브라우저의 CDP 주소를 사용하면 확대/축소, 모바일 동작 및 보안 정책도 검증할 수 있습니다. Playwright가 별도 위치에 설치되어 있으면 `PLAYWRIGHT_MODULE`을 지정합니다.

```bash
node tests/chart-browser.cjs "$CDP_URL" http://127.0.0.1:8000
node tests/security-browser.cjs "$CDP_URL" http://127.0.0.1:8000
```
