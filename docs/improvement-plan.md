# 분산일 대시보드 개선 설계 (IBD 정의 완전 반영)

`docs/memory.md`의 정확한 분산일 정의를 기준으로, 현재 시스템이 빠뜨린 규칙을 채우고 판단 가치를 높이는 설계다. 3개 관점(신호 충실도·대시보드 UX·한국 시장 특화)의 독립 설계를 종합했다.

## 핵심 진단

현재 시스템은 IBD 규칙 6가지 중 **1가지만** 구현돼 있다.

| IBD 규칙 (memory.md) | 현재 상태 |
|---|---|
| 종가 -0.2% 하락 + 거래량 증가 = 분산일 | ✅ 구현 ([_market.py](../api/_market.py) `enrich_rows`) |
| **롤링 25거래일 창에서만 카운트** | △ `one_year_rows[-25:]`로 근사 — 개별 소멸 규칙 없음 |
| **종가 대비 +5% 상승 시 개별 분산일 소멸** | ❌ 없음 → 과대 카운트 |
| **정체일(Stalling Day)도 분산일로 카운트** | ❌ 없음 |
| **Follow-Through Day = 재진입 신호** | ❌ 없음 |
| 만기일·리밸런싱일 거래량 왜곡 제외 | ❌ 없음 → 가짜 신호 |

또한 memory.md는 "분산일은 **누적이 아니라 롤링 25거래일 창** 안에서만 센다"고 못박지만, 현재 UI는 "최근 1년 분산일 수"를 대표 지표처럼 노출한다 — IBD 개념상 의미가 약한 숫자다.

가장 큰 가치는 **① 카운팅 정확화 + ② 시장 국면 판정**이다. 이 둘만으로도 "지금 몇 단계 위험인가"라는 실제 판단이 가능해진다.

---

## Tier 1 — 카운팅 정확화 + 국면 판정 (우선순위 최상, 난이도 낮음)

세 관점이 모두 최우선(5)으로 꼽은 항목. 데이터·구조 변경 없이 계산 로직만 보강한다.

### 1-A. 개별 분산일 소멸 규칙 (5% 회복 + 25거래일 경과)

평가 시점 T에서 각 분산일 D의 생존 여부를 판정한다.

```
D가 살아있음(active) ⟺
    D가 최근 25거래일 창 안에 있고          # 25거래일 경과 시 소멸
    AND  max(close[D+1 … T]) < close[D] × 1.05   # 이후 5% 이상 상승하면 소멸
```

- **유효 분산일 수** = active 개수 → 이게 국면 판정의 입력값이 된다.
- 구현 위치: [_market.py](../api/_market.py) `market_payload()`의 `recent25_distribution` 계산부를 위 규칙으로 교체. 각 행에 `expired: bool`, `expiredReason: "25일경과"|"5%회복"|null` 필드 추가.

### 1-B. 시장 국면 배지 (IBD Market Pulse 3단계)

유효 분산일 수로 memory.md의 3단계를 그대로 표시한다.

| 유효 분산일 | 국면 | 색 | 대응 문구 |
|---|---|---|---|
| 0–2 | 확인된 상승추세 | 녹색 | 정상 비중 운용 |
| 3–4 | 상승추세 압박 | 황색 | 신규 매수 축소, 손절 엄격 |
| 5+ | 조정 국면 경고 | 적색 | 현금 비중 확대, 신규 진입 중단 |

- UI: 요약 카드 최상단에 큰 배지 하나. 현재 "최근 1년 분산일" 카드를 이 배지로 대체(1년 수치는 보조로 강등).
- payload에 `phase: {level, label, count, action}` 추가.

### 1-C. 단기 클러스터 경고

memory.md: "2~3주에 4~5개가 몰릴 때가 위험." 25일 창과 별개로 **최근 약 10거래일(2주) 내 유효 분산일 ≥ 4**면 배지 아래 경고 배너.

**Tier 1 산출물**: 헤드라인 숫자가 "5% 회복분을 제거한 진짜 유효 카운트"로 바뀌고, 신호등 배지로 국면이 한눈에 보인다.

## Tier 2 — 신호 종류 확장 (우선순위 상, 난이도 중)

### 2-A. 정체일(Stalling Day) 판정 — OHLC 필요(확보됨)

상승 마감이라도 거래량 급증 + 종가가 저가권 = 매도벽. 분산일과 동일 카운트.

```
stalling ⟺
    closeChangePct ≥ 0            # 하락 아님(하락이면 이미 분산일 후보)
    AND volume > prev_volume       # 거래량 증가
    AND (close − low)/(high − low) ≤ 0.35   # 종가가 일중 하위 35%
    AND closeChangePct < 0.6       # 상승폭 미미(막힌 상승)
```

- 임계값(0.35, 0.6%)은 IBD가 공식 수치를 공개하지 않아 **튜닝 대상**. 상수로 노출.
- 유효 분산일 수에 정체일도 합산.

### 2-B. 차트 마커 체계 개편

현재는 빨간 점 하나뿐. OHLC·소멸·정체·FTD를 구분 표시한다.

| 마커 | 의미 |
|---|---|
| 채운 빨강 | 유효 분산일 |
| 빈 회색 | 소멸된 분산일 |
| 주황 | 정체일 |
| 녹색 ▲ | Follow-Through Day |
| 테두리 강조 | 만기일(왜곡 의심) |

### 2-C. 만기일 노이즈 필터 — 달력 계산 기반

memory.md의 "만기일·리밸런싱일 거래량 튐" 문제를 코드로 처리한다.

- **한국** 월물 옵션 만기: 매월 **둘째 목요일** / 분기 위칭(선물+옵션): **3·6·9·12월 둘째 목요일**
- **미국** 분기 위칭: **3·6·9·12월 셋째 금요일**
- 해당일 분산일에 "만기일" 배지. **카운트 제외 토글** 제공(기본: 표시하되 카운트 포함, 사용자가 끌 수 있음).

## Tier 3 — 재진입 신호 · 시장별 보정 (우선순위 중)

### 3-A. Follow-Through Day 탐지

memory.md: "저점 형성 후 4일째 이후 거래량 증가 + 1.25% 이상 상승" = 조정 후 재진입 신호. 분산일과 짝 개념.

```
1. 최근 저점(rally attempt low) 식별
2. 저점 이후 4거래일째 이상에서
   closeChangePct ≥ 1.25 AND volume > prev_volume → FTD
```

- 저점 정의가 다소 주관적이라 난이도 높음. 국면 배지가 적색일 때만 탐지·표시하면 실용적.

### 3-B. 코스닥 신호 품질 보정

memory.md: "코스닥은 개인 비중 높아 신호 품질 낮음." 코스닥 선택 시 **신뢰도 경고 각주** + 선택적으로 거래량 임계 강화(단순 증가 → 전일 대비 +일정% 이상).

### 3-C. 지수별 파라미터 프로파일

미국 IBD 표준 vs 한국 보정을 구조화(하락 임계·정체일 임계·만기일 규칙을 지수별 dict로). `INDEXES`에 `profile` 키 추가.

### 3-D. 매집일(Accumulation Day) · 순압력

반대 개념(거래량 증가 + 상승)을 카운트해 **순압력 = 분산일 − 매집일**을 보조 지표로. 분산일만 볼 때보다 국면 해석이 안정적.

## Tier 4 — 향후 확장 (데이터 연동 필요)

- **외국인·기관 수급 / 프로그램 매매 교차 확인**: memory.md가 "코스피는 이 데이터와 교차 확인이 낫다"고 명시. 별도 API 필요 → 현재 범위 밖. KRX 오픈API의 투자자별 거래실적 엔드포인트 구독 시 가능.

## 후행성 한계 표시 (공통)

memory.md: "분산일은 후행 지표 — 5개 쌓였을 땐 이미 상당히 빠진 경우가 많다." 국면 배지 옆에 **"후행 지표 — 확인 신호이지 예측 신호 아님"** 상시 각주로 오해를 방지한다.

## 권장 착수 순서

**Tier 1(1-A·1-B·1-C)부터.** 데이터·의존성 추가 없이 계산·UI만 손보면 되고, "지금 몇 단계 위험인가"라는 핵심 판단이 바로 생긴다. 그다음 정체일(2-A)과 만기일 필터(2-C)로 신호 품질을 올리고, FTD·수급(Tier 3~4)은 실사용 피드백을 본 뒤 결정한다.
